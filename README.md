# ☕ NEXUS BOOK CLUB 📚

## About Nexus

Nexus Book Club is a community of readers based in Machakos, Kenya, created to inspire lifelong learning, meaningful conversations and lasting relationships through literature.

## Vision

To build a vibrant community of readers who inspire lifelong learning, meaningful conversations and lasting relationships.

## Mission

To provide an inclusive platform where individuals connect through literature, exchange ideas freely, strengthen communication skills and cultivate personal and intellectual growth.

## Features

- 📖 Current book updates
- 👥 Member registration system
- 💬 Community discussions powered by Giscus
- 📜 Club constitution access
- 📚 Dynamic reading updates
- ☕ Coffee-inspired design theme

## Technology Used

- HTML5
- CSS3
- JavaScript
- JSON

- Giscus Discussions
- GitHub Pages
